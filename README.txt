FreeCinema PWA
==============

这是一个无需 Xcode 的网页版/PWA。

最快使用：
1. 把本文件夹上传到任意静态网页托管：
   - GitHub Pages
   - Cloudflare Pages
   - Netlify
   - Vercel
2. 用 iPhone Safari 打开网址。
3. Safari 分享按钮 -> 添加到主屏幕。

注意：
- 片源来自 Internet Archive 的公开/公共领域影视。
- 这个版本不破解任何付费平台、会员或 DRM。
- 直接双击 index.html 也能在 Mac 浏览器里测试，但“添加到主屏幕”和离线缓存通常需要 HTTPS 网站。
